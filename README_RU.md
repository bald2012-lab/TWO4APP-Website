# TWO4APP — веб-сайт (черновая версия)

Полностью автономный статический сайт на немецком и английском. Нет зависимостей, серверного кода, рекламных трекеров, форм, аналитики, внешних шрифтов или cookies, устанавливаемых самим проектом.

## Главные страницы

- `index.html` — главная на немецком; `en/index.html` — английская.
- `de/vergissmeinnicht.html` / `en/vergissmeinnicht.html` — приложение.
- `privacy/vergissmeinnicht.html` — ПОСТОЯННЫЙ URL для Google Play (двуязычная HTML-страница, доступна без JavaScript).
- `de/datenschutz-vergissmeinnicht.html`, `en/privacy-vergissmeinnicht.html` — локализованная информация.
- Общие разделы `datenschutz`, `impressum`, `terms`, `copyright`, `contact`, `support` и предупреждения в папках `de/`, `en/`.

## Важно до публикации

Это **черновик, не юридически завершённая публичная версия**. Сначала заполнить:

1. Полное юридическое имя физлица/юридического лица, отвечающего за TWO4APP.
2. Фактический почтовый адрес для Impressum.
3. Действующий адрес e-mail поддержки/Datenschutz (создать почту в домене two4app.de).
4. Фактический провайдер размещения, характеристики серверных логов/срок хранения, возможные передачи данных в третьи страны.
5. Проверить юридические тексты с учётом реальной деятельности и статуса предпринимателя.
6. После внедрения Google Play Billing обновить именно **приложенческую** Datenschutzerklärung, а не только общую.
7. Удалить баннер DRAFT, заменить robots.txt на разрешение индексирования, проверить и активировать ссылки поддержки.
8. Проверить страницы на мобильном телефоне и протестировать все ссылки.

**Нельзя** ставить этот черновой URL в Play Console до заполнения обязательных сведений.

## Как разместить в GitHub Pages

Рекомендуется новый отдельный публичный репозиторий `TWO4APP-Website` под GitHub-аккаунтом `bald2012-lab`.

1. Создать репозиторий, загрузить в его корень **содержимое этой папки**, а не папку целиком.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Проверить временный адрес вида `https://bald2012-lab.github.io/TWO4APP-Website/`. Важно: внутренние ссылки относительные, поэтому сайт работает и под префиксом репозитория.
4. В Settings → Pages → Custom domain вписать `two4app.de`, сохранить. DNS изменять **только после этого**.
5. У регистратора домена добавить 4 A-записи для `@`: `185.199.108.153`, `.109.153`, `.110.153`, `.111.153` (полные значения в документации). При необходимости `www` CNAME → `bald2012-lab.github.io`.
6. После проверки DNS включить `Enforce HTTPS`; проверить `https://two4app.de/privacy/vergissmeinnicht.html`.

Официальная документация: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

В этом архиве **нет CNAME** специально: сначала нужно создать и проверить GitHub Pages, затем привязать домен, чтобы не рисковать его захватом при неправильном DNS.

## Проверка локально

Можно открыть `index.html` напрямую. Для проверки маршрутов из корня папки:

```bash
python3 -m http.server 8080
```

Потом открыть http://localhost:8080/.
