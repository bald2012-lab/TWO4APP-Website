# Размещение сайта TWO4APP — действия владельца

## Статус

Сайт технически подготовлен, но **публичный запуск не разрешён**, пока не заполнены Impressum, Datenschutz и реальная контактная почта. До этого сайт содержит баннер `ENTWURF` и запрещает индексирование в `robots.txt`.

## A. Создать репозиторий (один раз)

1. Откройте **https://github.com/new?name=TWO4APP-Website** под аккаунтом `bald2012-lab`.
2. Имя: **TWO4APP-Website**, видимость: **Public**.
3. Нажмите **Create repository**. Удобнее создать пустой репозиторий без дополнительного README.
4. Вернитесь в ChatGPT и отправьте **«Репозиторий создан»**. Тогда загружать уже готовые файлы можно с помощью подключённого GitHub без ручного копирования 30 файлов.

Альтернатива: на новой странице репозитория нажмите **uploading an existing file**, распакуйте ZIP, перетащите файлы и папки **в корень** репозитория и нажмите Commit changes.

## B. GitHub Pages

На странице репозитория откройте **Settings → Pages**. В `Build and deployment` выберите `Deploy from a branch`, затем `main` и `/ (root)`, нажмите Save. Временный адрес будет `https://bald2012-lab.github.io/TWO4APP-Website/`. Но для публичного сайта обязательно сначала завершите юридические данные, иначе сайт остаётся рабочим черновиком.

## C. Домен

**Сначала** привяжите `two4app.de` в `Settings → Pages → Custom domain` и нажмите Save. GitHub создаст корневой `CNAME`. **Только после этого** у регистратора домена настройте A-записи `@` на адреса GitHub Pages:

- `185.199.108.153`
- `185.199.109.153`
- `185.199.110.153`
- `185.199.111.153`

Для `www` можно добавить CNAME на `bald2012-lab.github.io`. GitHub рекомендует предварительно подтвердить право собственности на домен. После проверки DNS включите **Enforce HTTPS**.

Официальная документация: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## D. Юридические данные (обязательно перед публикацией)

- Правовое имя владельца TWO4APP;
- полный почтовый адрес для Impressum;
- действующая почта для поддержки и защиты данных;
- сведения о хостинге, логировании и обработке данных, проверенные по фактическому провайдеру;
- при необходимости регистрационные и налоговые реквизиты;
- перед включением платежей — обновлённая Datenschutzerklärung и условия покупок;
- снять баннер `ENTWURF`, разрешить индексирование только после завершения юридической проверки.

## E. Настройка приложения

Для Google Play после публикации, заполнения юридических данных и проверки HTTPS: `https://two4app.de/privacy/vergissmeinnicht.html`.
Этот URL **не нужно** вводить в Play Console до завершения сайта. Существующую APK изменять не требуется только ради обновления текста на сайте; переходы на сайт из приложения — отдельная согласованная доработка версии 1.21.
